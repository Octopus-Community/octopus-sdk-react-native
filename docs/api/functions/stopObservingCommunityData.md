# Function: stopObservingCommunityData()

> **stopObservingCommunityData**(): `Promise`\<`void`\>

Stops the active community-data observation started by [startObservingCommunityData](startObservingCommunityData.md).
A no-op if no observation is active.

## Returns

`Promise`\<`void`\>

A promise that resolves once the observation has been torn down.
