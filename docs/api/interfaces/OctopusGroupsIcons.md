# Interface: OctopusGroupsIcons

Icons of the group (topic) selection and navigation.

## Properties

### openList?

> `optional` **openList**: `ImageResolvedAssetSource`

Opens the list of groups (the topic selector).

---

### selected?

> `optional` **selected**: `ImageResolvedAssetSource`

Marks the selected group in a list.

---

### viewGroup?

> `optional` **viewGroup**: `ImageResolvedAssetSource`

Opens a group from a content.
